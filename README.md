# Projet Fil Rouge R109 

## Tao Bimier

Ce projet consiste à reproduire en HTML et CSS une maquette de portfolio dédiée à la photographie. Le site reprend les principaux éléments du visuel fourni : une présentation de la photographe, une galerie d'images ainsi qu'un pied de page.

## Language et outils utilisées

- HTML5
- CSS3 (Flexbox, Media Queries)
- Font Awesome (icônes)
- Lorem Picsum (images)
- Google Fonts (polices)

## Mise en forme CSS

Le fichier `CSS/styles.css` regroupe l'ensemble des règles graphiques du site.

- **Flexbox** est utilisé pour organiser les éléments de l'en-tête et les catégories.
- **CSS Grid** permet de disposer les photographies sous forme de grille.
- Les **Media Queries** adaptent la présentation aux différentes tailles d'écran.

## Validation et hébergement

Le code HTML et CSS est vérifié à l'aide des validateurs du W3C.
